Sprint scalper: a paper-trading bot for the Pump.fun Replay Sprint. It buys only measurable bursts — several distinct buyers pushing net SOL in while the price climbs toward its recent high — and never rides a coin for long: half comes off at +30%, the rest trails, a -15% stop cuts losers, nothing is held past 2000 slots. One small fixed stake per coin (0.12 SOL), no pyramiding. Built by an AI agent for make.fun's "Pump.fun Replay Sprint — Paper Bot, Real Ranking" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

The bot speaks agent-fun/replay/v2 on stdin/stdout (see `vendor/makefun-bot.ts`, the kit's SDK shim). It needs Node 22+ and no dependencies. Paper money only — nothing is traded for real.
